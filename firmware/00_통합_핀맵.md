# 통합 핀맵 — 책상 위 반려로봇 (최종)

`firmware/main_robot/main_robot.ino` 에서 실제로 선언한 핀과 1:1로 일치한다.
아두이노 우노 총 20개 I/O(D0~D13, A0~A5) 중 **12핀 사용, 8핀 여유**.

## 디지털 핀 (D0~D13)

| 핀 | 방향 | 연결 | 비고 |
|---|---|---|---|
| D0 (RX) | — | (USB 시리얼) | 디버그/명령용, 배선 안 함 |
| D1 (TX) | — | (USB 시리얼) | 디버그/명령용, 배선 안 함 |
| **D2** | IN | HC-06 TXD → | SoftwareSerial RX |
| **D3** ~PWM | OUT | 모터 우 IN2 | 방향(디지털로 사용) |
| **D4** | OUT | → HC-06 RXD | SoftwareSerial TX, **1k/2k 전압분배** |
| **D5** ~PWM | OUT | 모터 우 IN1 | 방향(디지털로 사용) |
| **D6** ~PWM | OUT | 모터 우 EN | **속도 PWM** |
| **D7** | IN | KY-022 비콘 L | 폴링, 38kHz 버스트 시 LOW |
| **D8** | IN | KY-022 비콘 R | 폴링, 38kHz 버스트 시 LOW |
| **D9** | OUT | 모터 좌 IN2 | 방향 |
| **D10** ~PWM | OUT | 모터 좌 IN1 | 방향(디지털로 사용) |
| **D11** ~PWM | OUT | 모터 좌 EN | **속도 PWM** |
| **D12** | IN | 초음파 ECHO | 직결, pulseIn |
| **D13** | OUT | 초음파 TRIG | 온보드 LED 공유 핀 |

## 아날로그 핀 (A0~A5)

| 핀 | 방향 | 연결 | 비고 |
|---|---|---|---|
| **A0** | IN | 낭떠러지 KY-032 OUT | 디지털 read(비교기 출력) |
| A1 | — | (여유) | |
| A2 | — | (여유) | |
| A3 | — | (여유) | |
| A4 | — | (여유) | I2C SDA — 확장 여지 |
| A5 | — | (여유) | I2C SCL — 확장 여지 |

## D4 전압분배 (HC-06 RXD 보호)
```
아두이노 D4 ──[1kΩ]──(분기점)──[2kΩ]── GND
                        │
                    HC-06 RXD
```

## PWM 핀 배정 확인
우노의 PWM 핀은 3·5·6·9·10·11. 모터 속도(EN)는 **D6(우)·D11(좌)** 두 개만 PWM이
필수이며 둘 다 PWM 핀에 배정됨. D3·D5·D9·D10 은 방향(IN)용이라 디지털 출력이면 충분.

## 이전 버전 대비 변경점 (센서 구성 변경)
- 낭떠러지: FC-51 **2개(A0/A1)** → **KY-032 1개(A0)**. 좌/우 구분 불가 → 복구 회전은 기본 방향 고정.
- **리드 스위치(A2) 제거** → 도킹 감지 센서 없음. 귀가 완료는 IR 세기(`IR_ARRIVE_STRENGTH`)로 근사 판정.

## 센서 극성 (코드 상수와 일치, 실측으로 조정)
| 항목 | 상수 | 기본값 | 의미 |
|---|---|---|---|
| 낭떠러지 | `CLIFF_SURFACE_STATE` | `LOW` | 바닥 있을 때 KY-032 출력. 낭떠러지는 반대값 |
| IR 수신 | `IR_ACTIVE_STATE` | `LOW` | 비콘 버스트 수신 시 KY-022 출력 |

## 전원
- 센서 5V·GND 공통.
- 모터는 **별도 배터리(7–12V)** → L298N. 아두이노 5V로 모터 구동 금지.
- 모든 GND 공통.
